# 🔴 SAWAAL 4: Jo maine KHUD dhoondha — 2 asli problem

Ye tune nahi poocha. Maine khud search karte waqt paaya.

## Problem 1 — Purana site abhi bhi live hai (SERIOUS)

Search karne pe ye mila:

```
https://aqua-perl-53b8.vercel.app     ← LIVE, Google index mein hai
```

Maine khola:
```
Title:      "AquaNexa (RokaDoctor) - RO Purifier Buy Online | Patna RO Service ₹100"
'₹100'      20 baar        ← PURANA RATE
'AquaNexa'  42 baar        ← PURANA NAAM
canonical:  apne aap pe    ← Google ise ALAG site samajh raha
sitemap:    22 URLs
```

### Ye khatarnak kyun hai

- Google ise **alag website** samajhta hai (canonical apne aap pe hai)
- **Duplicate content** — tera hi content do jagah
- **₹100 rate** dikha raha hai, tu ₹200 leta hai — customer confuse
- **AquaNexa naam** — GBP pe Aqua Perl hai = NAP mismatch
- **Tere asli site ki ranking khaa raha hai**

### Fix (2 minute, code change nahi)

1. Vercel kholo → **Projects**
2. `aqua-perl` naam ka project dhundo (ya jiska URL `aqua-perl-53b8` hai)
3. **Settings** → sabse neeche → **Delete Project**

> ⚠️ Confirm kar lena ki wo tera **purana/test** project hai. `ro-project` wala **mat delete karna** — wahi asli hai.

## Problem 2 — ro-project.vercel.app bhi index mein hai

```
https://ro-project.vercel.app  ← LIVE
canonical: https://rokadoctor.in  ✅ (ye theek hai)
```

Ye kam khatarnak hai kyunki canonical sahi hai. **Par phir bhi index mein aa raha hai.**

### Fix

Ye tera asli project hai, delete nahi karna. Do option:

**Option A (aasaan):** Vercel → Settings → Domains → `ro-project.vercel.app` ke aage **Edit** → **Redirect to** `rokadoctor.in` (308)

**Option B:** Main code mein middleware laga sakta hoon jo `.vercel.app` pe aane wale ko `rokadoctor.in` pe bhej de

**Bol de kaunsa — main option B kar sakta hoon.**
